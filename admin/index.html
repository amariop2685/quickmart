Entrar a la administración

Pega tu clave de acceso. Se guarda solo en este dispositivo.

¿Cómo consigo la clave?
  1. Entra a github.com con tu cuenta y abre Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Crea un token nuevo. En “Repository access” elige “Only select repositories” y marca solo quickmart.
  3. En “Permissions → Repository permissions”, deja Contents en “Read and write”.
  4. Genera el token, cópialo y pégalo aquí. No lo compartas con nadie.
